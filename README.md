# Dr. Migwambo — Beginner Web Development Project

This starter project has a small website and a Node.js/Express backend.

## Requirements
- Install Node.js (LTS) from https://nodejs.org if it is not installed.
- Visual Studio Code.

## Run it
1. Unzip this project.
2. Open the `dr_migwambo_dev` folder in VS Code (File → Open Folder).
3. Open Terminal → New Terminal.
4. Type `npm install` and press Enter. (Needs internet once to install Express.)
5. Type `npm start` and press Enter.
6. In your browser, open `http://localhost:3000`.

## Project map
- `server.js`: Node server (backend).
- `public/index.html`: page structure (HTML).
- `public/style.css`: appearance (CSS).
- `public/app.js`: browser interactions (JavaScript).

## Beginner roadmap
1. HTML: elements, links, forms and page structure.
2. CSS: layout, colors, responsive design.
3. JavaScript: events, functions, arrays and objects.
4. Node.js + Express: server and routes.
5. REST APIs: requests and responses.
6. Database: SQLite or PostgreSQL, replacing browser-only IndexedDB.
7. User accounts, file upload and cloud deployment.

**Important:** This starter currently stores documents in the browser's IndexedDB. The Express server is an introductory backend with a sample API route. File upload to the server, user authentication and cloud storage are later learning steps.
